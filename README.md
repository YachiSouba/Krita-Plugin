# Krita-Plugin
Made a Multiple Magic wand( auto lasso tool) and multiple lasso tool! (seperately)  
On Krita on bar above tap "Tools"  
Two options will occur;  
one is, Multiple lasso- making multiple selections with lasso tool without pressing shift (press ctrl+alt+l)  
second is, multiple magic wand- press on a object with definate shape and it auto selects the shape as a lasso selection.
